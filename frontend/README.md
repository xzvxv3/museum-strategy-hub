# Museum Flow 프런트엔드

React + Vite 기반 박물관 방문 분석 대시보드입니다. 화면은 FastAPI를 통해 현재 제공된 CSV 두 개의 실제 집계값을 표시합니다. 목업 수치로 대체하지 않습니다.

## 실행

저장소 루트의 별도 터미널에서 백엔드를 먼저 실행합니다.

```sh
backend/.venv/bin/python -m uvicorn app.main:app --app-dir backend --reload --host 127.0.0.1 --port 8000
```

프런트엔드 터미널:

```sh
cd frontend
npm install
npm run dev
```

http://localhost:5173 에 접속합니다. Vite가 `/api` 요청을 `http://127.0.0.1:8000`으로 전달합니다. 서버를 종료하려면 각 터미널에서 Ctrl+C를 누릅니다.

운영 빌드는 `npm run build`입니다. 배포 시에는 `/api`를 백엔드로 전달하는 리버스 프록시가 필요합니다. 다른 API 주소를 사용할 때는 `.env.local`에 `VITE_API_BASE_URL=https://your-api.example.com`을 설정한 뒤 빌드하고, 백엔드의 CORS 허용 출처도 실제 프런트엔드 주소로 설정합니다. API 비밀키는 이 변수에 넣지 않습니다.

## 실제 데이터 화면

인구는 화면·표·차트·전략 근거 문구에서 반올림한 정수로 표시합니다. 집계·평균·구성비·증감률은 원본 소수값으로 계산합니다. 개별 반올림값의 합은 표시된 총합과 다를 수 있습니다. 비율과 증감률은 소수를 유지합니다.

방문 추이는 정돈된 눈금·영역 표시·최다 기간 강조와 마우스/키보드 값 확인을 제공합니다. 시간대는 24시간 막대 차트로 표시하며 관측 행이 없는 시간은 점으로 구분합니다. 관객 구성에는 연령·성별의 일관된 색을 사용하는 100% 누적 막대를 제공합니다.

방문 현황의 요일×시간대 히트맵은 월~일, 00~23시의 합계입니다. 공통 필터가 적용되며, 칸 선택 시 반올림한 인구·관측일·행 수를 확인할 수 있습니다. ★는 최대값(동률 포함), 0은 실제 0, 빗금과 점은 관측 행 없음, –는 시간 필터 밖입니다. 색상 범위는 현재 선택의 최대값을 기준으로 바뀌며 요일별 관측일 수를 보정하지 않습니다. 모바일에서는 표 내부를 가로 스크롤합니다.

기본 테마는 딥 틸(`#176B68`)·아이보리(`#F7F6F2`), 사이드바는 `#163638`, 선택 강조는 골드입니다. 이전 기본 녹색 테마는 새 기본색으로 표시하고 별도 사용자 지정색은 유지합니다. 히트맵 클릭 시 상세 패널에 선택 칸의 인구·관측일·전체 선택 범위 내 비중·연령/성별 구성을 표시합니다. 선택 해제는 패널만 닫고 공통 필터를 유지합니다. 필터 변경 시 상세 선택은 초기화합니다.

홈과 방문 현황에는 실제 집계 기반 자동 인사이트(최다 요일/시간, 최대 연령/성별 집단, 이전 기간 증감)를 제공합니다. 없는 데이터로 인사이트를 생성하거나 원인을 단정하지 않습니다. 카드와 상세 패널의 짧은 전환 효과는 동작 줄이기 설정에서 비활성화됩니다.

- **홈:** 관객 구성 도넛, 이전 동일 길이 기간 대비 변화, 최다 방문 시간·집중 요일, 자동 인사이트, 분석·전략 진입.
- 홈의 데이터 분석·운영전략 이동 버튼은 제목 오른쪽(모바일에서는 제목 아래)에 있으며, 하단의 큰 진입 카드는 제거했습니다. 데이터 기준 안내는 상단 텍스트 버튼으로 제공합니다.
- **홈 중앙 도넛:** 네 연령·성별 집단의 실제 비중에 따라 분할합니다. 마우스·터치·키보드로 조각 또는 범례를 선택하면 중앙에 해당 집단 인구와 비중을 표시하며, 전체 보기로 총합 표시를 복원합니다. 옆에는 기간 증감·최다 시간·집중 요일을 표시합니다. 관측 현황·분석 범위 안내 카드와 하단 FST 요약은 홈에서 제거했습니다.
- **방문 현황:** 일·주·월별 선형·막대·원형 차트, 수치 표, 시간대·요일·연령별 집계.
- **관객 구성:** 20·30대와 성별 구성. 체류시간 유형은 제공하지 않습니다.
- **시설 비교·연관 방문:** FST 시설 규모 비교, SECD 월별 시설 쌍 집계. 선택 시설을 기준 또는 상대 시설로 조회할 수 있습니다.

시설 비교는 ‘시설 방문 순위’와 ‘연관 시설’ 두 카드에 상위 5개를 먼저 표시합니다. 전체 목록은 펼치기로 확인합니다. 월별 상세 표·집계 기준 펼치기는 제거했으며 상단 데이터 기준 안내에서 지표 정의를 확인합니다. 방문 순위는 시설 필터를 강조 대상으로 사용하며, 동일한 기간·연령·성별의 다른 시설도 함께 조회합니다. 선택 시설의 방문 수·전체 순위를 요약합니다. 연관 시설은 선택 시설의 기준/상대 역할을 드롭다운으로 바꿀 수 있으며, 시설 미선택 시 시설 쌍별 순위를 표시합니다. 두 카드에 각각 일별 방문 합계와 월 전체 시설 쌍 집계의 기간을 구분합니다.
- **운영전략:** 실제 집계값에 따른 시간대 운영·주요 연령/성별 집단·기간 변화 점검 제안. API에서 규칙으로 생성하며 GPT API를 사용하지 않습니다. 내보내기는 브라우저 인쇄 → PDF 저장입니다.

운영전략은 운영 포인트 → 시설별 방문 특성 → 분류·전략 선택 → 근거 차트·실행 방향 → 체크리스트 흐름입니다. 시설별 프로필에 주말/평일 평균, 상위 3시간 비중, 최대 관객 집단, 최근 비교 변화를 표시합니다. ‘전략 판정 근거 보기’에서 7개 규칙의 측정값·조건·제안/보류 이유를 확인합니다. 전략 순서는 효과·성공 확률 순위가 아닙니다.

전략 분류는 전체/방문 확대/운영 배치/관객 구성/시설 연계입니다. 숫자는 해당 조건에서 규칙 기준을 충족한 제안 수입니다. 데이터 존재만으로 같은 전략을 반복 생성하지 않습니다. 관측 부족은 판정 보류로, 충분히 관측됐지만 기준에 해당하지 않는 경우는 조정 신호 없음으로 표시합니다. 새벽 집계가 큰 시설에는 새벽 운영 대신 집계 범위 점검을 연결합니다. 모든 전략은 전용 체크리스트로 실행 계획을 만들 수 있습니다.

방문 변화 차트는 관측일 평균을 비교합니다. 직전 동일 길이 기간이 적절하면 우선 사용하고, 전체 연도처럼 비교 기간이 없으면 선택 범위 내 최근 3개 완전월과 직전 3개 완전월을 날짜와 함께 표시합니다. 기존 KPI의 합계 증감과는 다를 수 있습니다. SECD 연계 후보는 월 전체 기준, 역할을 구분한 시설 쌍 비중·양수 관측 월 수·한 달 편중을 평가합니다. 조건을 충족하지 않으면 전략이 0개일 수 있습니다. 상세 판정 기준과 선택적 분석 보고서 생성 방법은 [백엔드 안내](../backend/README.md)를 참고하세요.

실행 계획에는 체크리스트 4단계, 담당자, 목표일, 메모를 입력할 수 있습니다. 저장 버튼을 눌러 `localStorage`의 `culture-execution-plans-v1`에 저장하며, 단계 완료 수로 준비/진행 중/완료 상태를 표시합니다. 시설·기간·연령·성별·전략 분류가 같으면 같은 계획을 갱신하고, 다른 조건이면 별도 계획을 만듭니다. 미저장 변경은 화면·전략 이동 시 보관하지 않습니다. 저장 후 ‘실행 계획 보기’를 누르면 해당 계획이 열린 별도 실행 계획 화면으로 이동합니다.

왼쪽 ‘실행 계획’ 메뉴에서 저장 당시 조건·전략과 입력 내용을 열고 수정할 수 있습니다. 전체/준비/진행 중/완료 필터, 상태별 건수, 담당자·목표일·진행률을 표시합니다. 분석 공통 필터는 이 화면에 적용하지 않으며 모든 저장 계획을 관리합니다. 분석 API 연결 없이도 계획을 열고 수정할 수 있습니다. 기존 저장 데이터는 그대로 사용합니다. 새로고침 후에도 계획은 남지만 다른 브라우저·기기와 동기화되지는 않습니다.
- **설정:** 테마, 기본 차트 형태, 계정 정보·알림 선호의 기기 저장, 원본 전체 품질 집계.

공통 필터는 시설·분석 기간·성별·연령입니다. 시작·종료 시간 입력은 제거하고 항상 00~23시를 분석합니다. 기본은 전체 시설·전체 제공 기간·20/30대·전체 성별·00~23시입니다. 방문 차트와 전략은 같은 필터를 사용합니다. 빠르게 조건을 바꾸면 이전 요청을 취소하고, 현재 조회가 끝날 때까지 이전 수치를 숨깁니다. 오류 시 재시도 버튼을 제공하고 데이터가 없을 때는 빈 결과를 표시합니다.

시작·종료일은 하나의 ‘분석 기간’ 버튼으로 선택합니다. 달력에서 두 날짜를 차례로 선택한 뒤 ‘기간 적용’을 누르면 한 번에 반영됩니다. 같은 날짜를 두 번 선택하면 하루 조회, 다른 월로 이동하면 월을 넘는 범위 조회가 가능합니다. 두 번째 날짜가 더 이르면 자동으로 앞뒤를 정렬합니다. ‘제공 기간 전체’로 CSV 전체 범위를 지정할 수 있고, 취소·Escape는 기존 필터를 유지합니다. 선택 가능한 날짜는 CSV 제공 범위 내로 제한합니다.

SECD는 월 단위이므로 선택일이 포함된 월 전체를 조회하고 시간 필터는 무시합니다. 화면에 해당 범위를 따로 표시합니다. FST 대비 비율이나 이동 순서로 해석하지 않습니다.

이전 기간 비교는 선택 기간과 동일 일수의 직전 기간이 CSV 제공 범위 내에 있을 때만 표시합니다. 이전 합계가 0이거나 관측 행이 없으면 증감률을 산출하지 않습니다. 누락 조합을 0으로 채우거나 요일 차이를 보정하지 않습니다. 주별 집계는 월요일 시작이며 양끝은 부분 주일 수 있습니다.

로그아웃하면 데모 로그인 화면을 볼 수 있습니다 (`abcd` / `1234`). 실제 인증·권한·비밀번호 변경·이메일 발송은 제공하지 않습니다. 로그인 화면은 보안 경계가 아닙니다.

## 계획 관리와 내보내기

- 공통 분석 필터는 이 브라우저에 저장되어 새로고침 후 복원됩니다. 초기화하면 전체 범위로 돌아갑니다.
- 실행 계획의 미저장 내용은 계획별로 현재 탭의 `sessionStorage`에 임시 보관합니다. 화면 이동과 새로고침 후 같은 계획에서 복원되며, 탭을 닫으면 임시 보관은 종료됩니다. 정식 보관은 저장 버튼을 사용합니다.
- 실행 계획에서 전략·시설·담당자·메모 검색, 최근 수정순·목표일순·이름순 정렬과 보관함 이동/복원이 가능합니다. 보관한 계획은 홈의 진행 현황과 목표일에서 제외합니다.
- 백업 다운로드는 보관함을 포함한 모든 저장 계획의 JSON을 내보냅니다. 가져오기는 10MB·5,000개 이하의 유효한 Museum Flow v1 백업을 병합하며, 동일 ID의 기존 계획은 유지합니다. 임시 작성 내용은 백업에 포함하지 않습니다.
- 방문 집계 CSV는 선택 조건의 일/주/월 추이·차원별 집계·관객 구성·요일×시간 관측 셀을 구분하여 내보냅니다. 각 집계는 별도 관점이므로 행 전체를 합산하지 않습니다. 누락 셀은 생성하지 않으며 계산된 소수점 값을 유지합니다. 시설 순위·연관 방문은 각각 카드에서 내보냅니다. 연관 방문 CSV는 월별 시설 쌍 집계이며 연령·성별 열은 적용된 필터 조건입니다.
- PDF 인쇄에는 메모 전체를 줄바꿈과 함께 출력합니다.

추가 기능 브라우저 검증: `node scripts/verify-improvements.mjs`. 긴 메모 출력 결과는 `/tmp/culture-improvements.pdf`, 모바일 계획 관리 화면은 `/tmp/culture-improvements-mobile.png`에 생성합니다.
